# Current documentation

The authoritative documents for the molecular reaction platform are:

1. `reaction_discovery_platform.md` - purpose, scientific gates, architecture,
   public artifacts, production workflows, and remaining validation.
2. `stage_io_reference.md` - stage ownership and artifact flow.
3. `developer_architecture.md` - source-code boundaries and extension rules.
4. `production_environment.md` - external-program setup and capability checks.
5. `m3_real_quantum_chemistry_validation.md` - completed HCN/HNC path, TS, IRC,
   thermochemistry, and activation-barrier validation.
6. `m3_amine_hf_application_validation.md` - bounded TMA(HF)2 search and its
   current DFT basin/path validation status.
7. `production_science_validation_plan.md` - the cross-molecule validation
   matrix needed before amine/HF candidate ranking.
8. `extension_backlog.md` - only scientifically material work that remains.
9. `implementation_status.md` - implemented capabilities versus completed real
   quantum-chemical evidence.

Retired HF endpoint-enumeration, numbered implementation phases, and wet-etch
surface-proxy notes are not contracts for the current molecular core.
