# Current documentation index

This directory contains the current documentation for the HF gas-phase reactivity workflow.  Historical phase notes remain in `docs/PHASE*.md` for traceability.

## User-facing docs

1. `hf_gas_reactivity_technical_report.md` — technical report for chemists and reaction/process engineers.
2. `user_guide.md` — how to run and inspect the workflow.
3. `output_reference.md` — what files are produced and which ones to open.
4. `science_gate.md` — screening/scientific/production evidence rules.
5. `production_checklist.md` — checks before using results for candidate selection.
6. `final_review.md` — compact review of what is ready and what is not.

## Developer docs

1. `developer_architecture.md` — package boundaries and code layout.
2. `stage_io_reference.md` — stage-by-stage input/output reference.
3. `backend_extension_guide.md` — how to add simulation or database backends.
4. `extension_points.md` — small extension patterns.
5. `code_maintenance.md` — maintenance rules to avoid unnecessary complexity.

## Future work docs

1. `future_chemistry_methods.md` — chemistry and simulation method roadmap.
2. `extension_backlog.md` — prioritized backlog.
3. `production_science_validation_plan.md` — validation plan for real scientific use.
