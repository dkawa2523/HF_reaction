調査で分かった主な事実は次のとおり。

1. **S6 の失敗は偶然ではない。** 初期 Hessian で負にするモードを「反応方向と最も平行な固有ベクトル」で選んでいて、その反応方向に OH の回転が混ざっている。平らな PES では、ほぼ縮退した固有ベクトルの向きが少しの差で回り、回転子のモードが選ばれる。仮説の結合変化ベクトル ρ(切れる結合を伸ばし、できる結合を縮める向き)だけを負にしたモデル Hessian では、VAL7 と同じ種から 14 歩で引き抜きの領域に着いた(従来は 41 歩で −73i)。ただし着いた点は OH のねじれの極大に立つ二次の鞍点(−490.0i / −81.9i)で、一次の TS(−504.3i / −37.7i)に着くには既存の higher_order_retry が 1 回要る。
2. **S5 の「結論が出ない」の大部分は、多参照性ではなく問いの立て方から来ている。**
   - 経路の各点を atomic guess から別々に解くので、点ごとに別の SCF の枝に落ち、+25〜29 kcal/mol の偽の山ができる。
   - 障壁のない会合を「極小 → 極小」の形で問うていて、その「極小」は broken-symmetry(BS)の UKS に混ざった四重項がつくった人工物である。
   - C–O を固定した緩和スキャンに Yamaguchi の近似スピン射影(AP)をかけると、二重項の面は単調に下る(障壁なし)。
   - 多参照法による定量的なエネルギーは、引き続き範囲外とする。
3. **W3 と VAL7 で S6 の区分が入れ替わったのは、主に決定的な原因による。** 並列計算の非決定性も一因だが、次の 3 つが重なっている。
   - 分割した子 case の端点に basin の代表 species の添字を使い、同じ状態の置換異性どうしに偽の 4 結合変化ができた。
   - 結合が変わる case を basin の粒度で判定している。
   - 仮説の重複除去で、低レベルの TS を 1 つしか残さない。
4. **既定の順位のエネルギー(PBE0-D3BJ/def2-SVPD)は、CCSD(T)/def2-TZVPD に対して平均 2.7、最大 6.2 kcal/mol ずれる**(4 反応の実測)。誤差の主因は汎関数で、基底ではない。M06-2X-D3(0)/def2-TZVPD の一点計算を層にすると平均 1.0、最大 1.8 kcal/mol になる。17 原子で 1 点 255 s で、ωB97X-D3 の約 1/6.6 の費用である。
5. **コード量の未達(+273 行)のうち、SLOC の増分は +121 で、残りは docstring(+127)と空行(+32)である。** 一方、同じ化学操作(QRC の変位、像の判定、極小のストア)を 2〜3 か所で別々に実装している重複は実在する。

### 0.2 共通する根本原因

課題の多くは、次の 6 つの根本原因のどれかに行き着く。

- **A. 仮説が定める化学的な同一性が、探索・判定・分割まで運ばれていない。** 同一性とは、結合変化の向き、原子の対応(添字)、状態の粒度の 3 つである。
  - 探索は、経路の接線から作った「反応方向」で負のモードを選ぶ(G1)。
  - TS のゲートは、虚モードの本数しか見ない(G1)。
  - 子 case の端点は basin の代表の添字になる(G8、G5)。
  - 結合が変わる case を basin の粒度で判定する(G8)。
- **B. 連続量を 1 本のしきい値で 2 値化し、同じ性質を複数の検出器で別々に決めている。**
  - 結合のしきい値 Σr_cov + 0.4 Å(G4 の R6、G8-2)
  - 対称性の 4 つの検出器(直線性の階数、回転定数の床、libmsym、is_chiral。G5-2)
  - noise / soft / saddle の帯の非対称(G3)
  - 停留性を最低振動数だけで判定していること(G5-1)
- **C. 問いの形が PES の型に合っていない。**
  - 障壁のない会合を「極小 → 極小」で問う(G2)。
  - BS の汚染を補正せずに捨てる(G2)。
  - SCF の枝を混ぜたプロファイルで山を判定する(G2)。
  - 鞍点がないかもしれない会合に、鞍点探索を上限なしで再開させる(G1)。
- **D. 継続・再試行・予算の規則が、失敗の種類ごとにばらばらである。**
  - autoz の失敗は最初の構造からやり直す(G4、G8)。
  - 無害な AUTOZ の通知を致命的な失敗と誤って分類する(G8)。
  - maxiter からの再開には上限がない(G1)。
  - 続きの試行の数え方が一貫していない(G3)。
  - 決定表に到達できない行がある(G3、G7)。
- **E. 同じ化学操作を複数の場所で実装している(G7、G4)。** 片方だけに規則(像の省略、既知 basin での freq 省略)が入り、残りの一致は「既定値でたまたま同じ」に頼っている。
- **F. 順位のエネルギーが、停留点レベルの PBE0 のエネルギーそのものである(G6)。** 非局在化誤差で 3 中心の TS を過安定化する。さらに PBE0 は PES の形そのもの(早く平らな TS)も変えるので、S6 の平らな PES の問題(G1)ともつながる。

### 0.3 抜本的な改良の方向性

1. **仮説の結合変化を、探索と判定の一次情報にする**(§3 X1)。ρ に負の曲率を 1 本だけ置くモデル Hessian で探し、虚モードが ρ の部分空間を担うこと(χ)を TS の必要条件にする。
2. **原子の対応を連続させ、判定の粒度を「端点が異なる粒度」にそろえる**(§3 X2)。派生する case の端点は、実際に到達した添字付きの構造にする。結合が変わる case は化学状態の粒度で判定する。仮説は、状態の組が同じなら 1 つにまとめ、別々の低レベル TS をすべて種として持つ。
3. **しきい値の近くの判定は、分解能で定義する**(§3 X3)。
   - 結合の変化はヒステリシス帯で判定する。
   - 点群は、対称化した構造が元と同じ basin に入るかどうかで受け入れ、直線性・σ・m・射影をそこから導く。
   - 停留性は、その点の Hessian と勾配による二次モデルの降下量で判定する。
4. **PES の型に合った問いを立てる**(§3 X4)。低スピン結合の組成を 1 つのクラスとして分類する。障壁のない会合は、分離した単量体から付加体までの緩和スキャンと AP で判定する。開殻の経路は、SCF の連続した解の上で比べる。
5. **継続と予算の規則を 1 つにする**(§3 X5)。
   - 駆動系のジョブは、どの失敗でも最後の frame から続ける。
   - 同じ種の続きは段数付きで 1 試行として数える。
   - 再開は経路のエネルギーの上限で打ち切る。
   - 到達しない行(11、16)を決定表から削除する。
6. **既定の順位を M06-2X-D3(0)/def2-TZVPD // PBE0-D3BJ/def2-SVPD にする**(§3 X7)。整理と改良は、JobStore の再生ゲート(新しい QM ジョブ 0 件、かつ記録が同一)で守る(§3 X8)。

## 2. 群ごとの詳細

### 2.1 G1 平らな PES の TS 探索(S6 OH + CH4、S5 の saddle の空回り)

#### 化学的背景

- **反応と参照値**
  - 反応は OH• + CH4 → H2O + CH3•(二重項)。
  - 高精度計算の TS は反応物寄りで、C–H–O はほぼ直線。r(C–H) は約 1.205 Å、r(O–H) は約 1.32 Å。
  - 古典障壁は CCSD(T)-F12 で 6.29 kcal/mol(PCCP 22, 14560 (2020))、HTBH38 の参照値は 6.7 kcal/mol。
  - W3 で得た PBE0 の TS(−481.1i)は、C–H 1.183、O–H 1.384、C···O 2.566 Å、∠CHO 176°。障壁は分離した反応物から 0.79 kcal/mol で、ハイブリッド汎関数が H 移動の障壁を系統的に低く出すこと(Zhao & Truhlar, JPCA 109, 2012 (2005)、平均符号付き誤差 −4.2)と整合する。
- **入口の錯体と平らな角度の PES**
  - OH···CH4 の vdW 錯体は D0 が 1 kcal/mol 未満で、OH と CH4 の内部回転はほぼ自由である(Wheeler et al., JCP 112, 6590 (2000)、Tsiouris et al., JCP 114, 187 (2001))。
  - そのため入口側には、向きの違う停留点が 0.1〜1 kcal/mol の幅に多数ある。
  - S6 で見つかった −73.0i・−70.4i・−58.6i・−57.3i の鞍点は、どれも C···O 3.26〜3.55 Å の向きを変えるだけの鞍点で、QRC の両側が同じ basin に戻るのは化学的に正しい。
- **TS の近くでモードが縮退する**
  - 早い TS では、反応座標の曲率が小さく、OH のねじれとほぼ縮退する。
  - W3 の path_hei の DFT Hessian では最低 2 本が −137.4i / −113.7i、W5 では −218.3i / −134.8i で、どちらも反応モードと回転子の混合だった。
  - ほぼ縮退した固有値の固有ベクトルは、構造がわずかに違うだけで大きく回る。
- **NWChem の saddle の挙動**
  - DRIVER の saddle は、最初は moddir のモードを登る。その後は、前の探索方向との overlap が最大値の 0.7 倍以上のモードのうち、最低固有値のものを追う(fuzzy maximum overlap。https://nwchemgit.github.io/Geometry-Optimization.html の MODDIR / VARDIR、FIRSTNEG、TRUST・SADSTP)。
  - 固有値が約 1e-4 Eh/bohr² の回転子の方向では歩幅が大きくなり、変位の収束条件を満たせないまま maxiter 50 に達する。
- **先行例**
  - 反応座標でモデル Hessian を修正する考え方は pysisyphus の TSOpt(`rx_coords` / `rx_modes`、https://pysisyphus.readthedocs.io/en/latest/tsoptimization.html)にある。
  - 反応結合を固定して TS を探す AutoTST(Bhoorasingh & West, PCCP 17, 32173 (2015))と KinBot(Van de Vijver & Zádor, CPC 248, 106947 (2020))も同じ系統。
  - 固有ベクトル追跡の原理は Baker, J. Comput. Chem. 7, 385 (1986)。

#### 根本原因

1. **負にするモードを「反応方向と最も平行な固有ベクトル」で選んでいる。その反応方向には OH の回転が混ざっている。**(記録とプローブで確認)
   - `Ctx.direction`(actions.py:172-185)は、経路の接線を `reaction_centre`(topology.py:68-75)の行に制限したものである。reaction_centre は変化する原子の隣接原子も含むので、S6 では 7 原子すべてが入る。VAL7 の screen_hei で、この方向と ρ の cos は 0.69 だった。
   - `shape_hessian`(vibrations.py:86-101)は、射影した Hessian の固有ベクトルのうち方向と |overlap| が最大の 1 本だけを符号反転する。
   - VAL7 の xTB Hessian では、overlap 0.79 の固有ベクトル(λ = +0.0028、変角とねじれ)が選ばれた。NWChem の Step 0 は `Search mode=1 eval=-1.4D-03` で、41 歩で −73.0i に収束した。
   - W5 の path_hei では DFT Hessian の最低 2 本がどちらも混合モードで、50 歩で回転子の領域に下った。成否は、ほぼ縮退した固有ベクトルがどちらに回るかで決まっている。
   - プローブ `/home/user/hfauto_r8_probe/G1/rhoonly`:
     - 同じ種と同じ xTB Hessian を使い、負の曲率を ρ̂ の 1 方向にだけ置いた(H0 = P·H₊·P − κρ̂ρ̂ᵀ、κ = 0.219)。
     - 14 歩で E −116.031215 に着いた。C–H 1.184、O–H 1.382、C···O 2.566 Å、∠178° で、引き抜きの TS の領域である。
   - 追加のプローブ `G1/rhofreq`: この点の freq は **−490.0i と −81.9i の二次の鞍点**(OH のねじれの対称な極大)だった。一次の TS(`G1/tsfreq`: −504.3i / −37.7i、E −116.031372)は、これより 0.10 kcal/mol 低い。したがって、ρ だけでは一次の TS に一度で着かない。既存の higher_order_retry が 1 回要る。
2. **TS のゲートは虚モードの本数しか見ず、虚モードが仮説の結合変化を担うかを確かめない。**(記録で確認)
   - `is_first_order_saddle`(gates.py:130-140)は、最低と 2 番目の振動数だけで判定する。
   - −73.0i は saddle_cm1 50 より硬いので、`_soft_ts_failed`(state.py:171-175)にも入らない。行 8 は same_basin を 2 振幅まで再試行するので、W5 では QRC の opt 2 本に 1,346 s・68 歩を払った。これは paths 段の QM 3,997 s の 34% にあたる。
   - 反応モード性 χ = ‖Q_Bᵀq̂‖ で分けられる。Q_B は変化する結合の Wilson 伸縮ベクトルを正規直交化したもの、q̂ は質量の重みを外して正規化した Cartesian の虚モード。
     - VAL7 と W3 で正しい TS 15 例は χ = 0.64〜0.83、向きを変えるだけの鞍点と S5 の −72i は 0.00〜0.06(scratchpad の g1/metric_orth.py)。
     - ただし正しい TS の標本は、すべて H 移動か H シフトである。
3. **xTB Hessian の採否を決める overlap テスト(`_MIN_OVERLAP` 0.3)は、原因 1 の帰結である。**(一部確認)
   - VAL7 で overlap 0.32 の xTB の虚モードは、水酸基の H の成分が 0.75、ρ との cos が 0.04 の回転子だった。

4. **maxiter で止まった saddle を、最終フレームのエネルギーを確かめずに再開する。**(記録で確認)
   - `refine_saddle`(actions.py:250-255)は Failure.final を saddle_restart の種にし、試行に数えない。行 14 は再開を無条件に実行する。

   - Failure(core/evidence.py:130-135)にはエネルギーの欄がない。
5. **S5 の会合は、この UKS の PES では鞍点をもたない可能性がある。**(未検証)
   - S5 の種の overlap は 0.66〜0.82 と高いので、方向の汚れは原因ではない。
   - string 上の ⟨S²⟩ は 0.758 → 0.806 → 1.71 と増えていて、山そのものが SCF の枝の不連続による見かけの山である可能性がある(G2 の原因 1 を参照)。
6. **既定の string は 1 チャンク(20 反復)を超えて続かない。**(コードで確認。G3 の原因 3 から引き継ぐ)FIND_PATH の種の質は、未収束の string の HEI で頭打ちになる。

**G1-P1(修正して採用、must)**

- 原理:
  - P-RFO の結果は、最初にどの方向を負にするかで決まる。そこで、その方向を仮説が定める ρ = Σ_broken ∇r − Σ_formed ∇r(剛体運動を射影したもの)にする。

- 変更:
  1. vibrations.py の `shape_hessian` を、方向 d を受け取るときは P·H₊·P − κd̂d̂ᵀ を返す 1 本の分岐にする。κ_min はモジュール定数 0.05 Eh/bohr²。
  2. 反応モードの種(`_MODE_SEEDS`)も、同じ式で d = 自分の虚モードとする。

  4. `_seed_hessian`(actions.py:216-229)の overlap テストと `_MIN_OVERLAP`(actions.py:57)を削除する。xTB Hessian は正の部分のモデルとしてそのまま使う。
  5. `peak_seed` は tangent を作らない。
  6. NWChem の入力(trust 0.1、sadstp 0.1、inhess 2、moddir 1)は変えない。
- 汎用性: ρ はラベル付きの結合変化だけから決まるので、元素・電荷・スピン・大きさに依らない。H 移動、SN2、プロトン移動、協奏反応に使える。平らな PES(vdW 錯体の入口と出口、回転子をもつラジカル)ほど効く。

#### 見送った案

- `_MIN_OVERLAP` を 0.35 に上げる: S6 の数値に合わせた調整にすぎない。W5 では DFT Hessian でも失敗している。
- saddle_cm1 を 80 cm⁻¹ に上げて、−73i を行 11 に入れる: 柔らかさは過程の種類と関係がない。本当に柔らかい TS まで崩壊扱いになる。

- NWChem の VARDIR、NOFIRSTNEG、sadstp の調整: VARDIR は autoz の番号 1 本しか指定できず、ρ のような組み合わせを表せない。

- 反応部分空間に限った dimer 法のエンジン、区別座標の緩和スキャンを標準にする: エンジンと契約が増え、string と役割が重なる。
- 結合変化を固定した種の拘束緩和(旧 G1-P4): ZCOORD の経路と autoz の再構築のリスクが増える。プローブで一度成功しただけで、G1-P1 と higher_order_retry で足りるはずである。S6 の実 run で G1-P1 が一次の TS に届かなかったときだけ再検討する。
- QRC の振幅や試行を増やす: その鞍点の両側は本当に同じ basin にある。
- W3 の −481i を ts_calc として貸す、期待値として固定する: 系に固有のパッチで、偽の合格になる。
- xTB の NEB や TS を種にする: GFN2 には OH···CH4 の錯体の極小がなく、VAL7 の NEB は TS を返さなかった。

- S5 の会合の正しい障壁の有無は、G1 では判定しない。G1-P2 と G1-P3 は資源の浪費と偽の reassigned_step を防ぐためだけに使い、会合そのものは G2(§3 X4)で扱う。

### 2.2 G2 開殻・ラジカル会合(S5 CH3• + O2)

#### 化学的背景

- **電子構造**
  - CH3•(S=1/2)と O2(X³Σg⁻、S=1)の組は、二重項と四重項に結合できる。結合をつくれるのは二重項の面だけで、生成物は CH3OO•(²A″)である。四重項の面は斥力的である。
  - 実験では障壁のない再結合として扱われる(k∞ ≈ 2×10⁻¹² cm³ s⁻¹。Fernandes, Luther, Troe, JPCA 110, 4442 (2006))。
  - 定量的な速度には、多参照の PES と VRC-TST が要る(Georgievskii & Klippenstein, JPCA 107, 9776 (2003))。
- **単参照 UKS で書ける状態**
  - 単量体(CH3 の ⟨S²⟩ 0.7544、O2 の三重項 2.0096)、CH3OO•(0.7545)、四重項の面(3.764)は正しく書ける。
  - 漸近の低スピン二重項は BS の単一行列式になる。⟨S²⟩ は (S_A−S_B)(S_A−S_B+1)+2S_B = 1.75 で、二重項 2/3 と四重項 1/3 の混合にあたる。**1.71 は誤りではなく、この構造から必然的に出る値である。**
  - 結合をつくる途中では、BS は連続して純粋な二重項につながる。Yamaguchi の近似スピン射影(AP)で四重項の混入を除ける。E_LS = E_BS + α(E_BS − E_HS)、α = (⟨S²⟩_BS − S(S+1)) / (⟨S²⟩_HS − ⟨S²⟩_BS)(Yamaguchi et al., CPL 149, 537 (1988)、Noodleman, JCP 74, 5737 (1981))。
  - 同じ Ms=1/2 には、O2 の π* 電子が対になった別の解(⟨S²⟩ 約 0.76、CH3 + O2(a¹Δg) 相当)もある。ROKS の二重項は、この枝しか表せない。
- **プローブ(PBE0-D3BJ/def2-SVPD、4 ranks)**

     - 端点の BS の vectors を順に引き継ぐと、⟨S²⟩ は 1.71 → 0.754 と連続に下がり、山は最大 +0.80 kcal/mol(解像度 1.0 未満)だった。
     - hfauto と同じ atomic guess では、フレーム 1〜5 が ⟨S²⟩ 0.76〜0.81 の枝に落ち、+28.9 / +23.7 / +18.1 / +11.9 / +5.1 kcal/mol の偽の山ができた。
  2. C–O を固定した緩和スキャン(`G2-1/scan/scan.log`)。値は分離した CH3 + O2 基準の kcal/mol、7 opt + 7 SP で約 10 分。

     |---|---|---|---|---|---|---|---|---|

  3. GFN2-xTB(`G2-2`)
     - 対の二重項は SCC が収束しない(HL gap 0.41 eV、rc 128)。
     - etemp を上げると収束するが、偽の束縛になる(1000 K で −15.7、3000 K で −30.6 kcal/mol)。

### 2.4 G4 計算コスト

#### 化学的背景と、計算プログラムの挙動

- **S19 TMA·(HF)2(17 原子)**

### 2.5 G5 再現性

#### 化学的背景と、計算プログラムの挙動

- **S6 の CH3OH···H**
  - H• が vdW だけで付いた緩い錯体で、PES はほぼ平らである。
  - W3 の肩(−116.01627243、−6.5i)、VAL7 の極小(−116.01642656)、本調査のプローブ A の終点(−116.01631645)が、0.1 kcal/mol 以内に 3 つ並ぶ。違うのは H• の位置だけで、どの停留点に止まるかは化学ではなく軌跡で決まる。
  - 平らな領域で軌跡が分かれるのは、並列の浮動小数点和の順序による。NWChem は積分のタスクを共有カウンタ(NXTVAL)で動的に配る(Demmel & Nguyen, IEEE TC 2015)。記録では、同じ job.nw(md5 3cc44410f8d3、-np 4)が 15 歩目まで一致し、16 歩目で 2e-8 Eh ずれた。
- **DRIVER の既定の収束**
  - gmax 4.5e-4、grms 3e-4、xmax 1.8e-3、xrms 1.2e-3。
  - W3 は 22 歩目で 4 条件をそろえた。このとき歩ごとの ΔE は 1e-8 程度で、EPREC 5e-6 より 2 桁以上小さい。
- **対称性**
  - H···H2 の真の極小は C∞v。軸から 0.006 Å ずれた構造を非直線として扱うと、振動が 3 本になり、G が 2.27 kcal/mol 変わる。
  - σ と m は点群から一意に決まる(Fernández-Ramos et al., TCA 118, 813 (2007))。
  - libmsym(https://github.com/mcodev31/libmsym)のしきい値は 6 つが相互に効くヒューリスティックで、単調ではない。
- **CREST 3.0.2 の乱数**
  - iMTD-GC の MD の初速は、`random_seed()`(引数なし)から作る。gfortran では OS のエントロピーで種が決まる(https://gcc.gnu.org/onlinedocs/gfortran/RANDOM_005fSEED.html)。
  - 固定種の経路は QCG の `-samerand` だけにつながっており、`-ttseed` はバイナリにない。
  - 一方、xTB は決定的である(S8 付加体の opt を 1 スレッドと 4 スレッドで 2 回ずつ流し、md5 が一致した)。
  - NT2 の単一の軌跡は初期条件に敏感で(Vaucher & Reiher, JCTC 14, 3091 (2018))、同じ化学の drive でも障壁が 76.65 と 92.3 kcal/mol に分かれた。

#### 根本原因

1. **平らな PES で、NWChem の最適化が非停留点(肩)で止まり、hfauto はそれを極小として登録する。**(コードと記録で確認)
   - input.py:130 は DRIVER の既定のまま。gates.py:73-81 は最低の振動数だけで tier を決め、−6.5i は noise になる。残差勾配はどこでも見ていない。
   - W3 では 05c1(−116.016272428、noise_imaginary_mode)と bfac(−116.016426504)が同じ状態の別の basin になった(ΔE 1.5e-4 Eh > 5e-5)。
   - 二次モデルの降下量 ΔE_N = Σ g_i²/(2|λ_i|)(プローブ `G5/newton_probe.py`): W3 の肩は 2.7e-4 Eh、VAL7 の DFT 極小 62 点は 1 点(1.2e-5)を除いて 5.4e-6 以下(中央値 約 1e-8)で、3 桁以上離れている。
   - プローブ `G5/cont/A`: 肩から Hessian 付きで続けると、13 歩で 3 つめの点(−116.01631645)に着いた。これは VAL7 の極小より 1.1e-4 Eh 上なので、5e-5 の基準ではやはり別の basin になる。
   - NXTVAL が原因であることの直接の証明はない。ただし結論には影響しない。
2. **分解能より細かい、同じ状態の basin の分裂。**(一部確認)
   - basin が分裂すること自体は正しい。
   - ただし W3 の S6 で分割の連鎖を直接起こしたのは、**分割の中間体の原子の番号付けの不整合**である(§2.8 の原因 1)。
   - hypotheses._auto(hypotheses.py:212)は、結合変化のない対をすでに捨てている。
3. **直線性・σ・キラリティを、4 つの検出器が別々のしきい値で決めている。**(コードとプローブで確認)
   - vibrations.py:21,53 の階数の比 1e-3、vibrations.py:108-116 の回転定数の床、thermo.py:44-61 の libmsym(equivalence 2e-3 だけ、例外なら σ=1)、identity.is_chiral(鏡像の RMSD 0.05 Å)の 4 つ。
   - S18 では、前の 2 つが非直線、libmsym が C∞v と判定していて矛盾している。
   - 軸へ射影した構造では、G−E の差が 2.27 → 0.006 kcal/mol に縮んだ(`G5/sym_probe*.py`)。
   - 1e-3 Å の揺らぎを 10 回加えると、今の設定では C3v 分子が 2〜3 回例外(σ=1)になる。全しきい値を 1e-2 にすると 11 構造すべてで 10/10 安定、5e-2 では誤る(I⁻···CH3I が Cs)。
   - acac は 1e-2 まで群が見つからず、鏡像の RMSD は 0.035 Å で is_chiral のしきい値 0.05 に近い。
4. **S8・S10 の件数の揺れは、CREST が同じ配座を違う番号付けで返すことと、trial の列挙が添字に依存することの重なりである。**(コードとプローブで確認)
   - trials.py:118-124 の key は丸めた距離、代表は「先に来たもの」、同点は添字の対で決まる。trial_id は添字を含むハッシュで、max_trials で打ち切る。

**G5-P4(修正して採用、should)**

- ExecutionSpec を JobStore の鍵に入れる、NWChem を 1 rank で走らせる: 同じ 4 rank でも和の順序は変わるので、決定性は得られない。
- すべての DFT opt に tight を付ける: VAL7 の opt 116 本のうち 67 本は最終 gmax が tight を超えていて、歩数が大きく増える。しかも tight でも、平らな PES でどの極小に落ちるかは決まらない。
- noise_cm1 を下げる: 問題は残差勾配で、虚振動数の大きさではない。
- CREST に種を渡す、fork する: 入口がなく、ツールの版の固定と矛盾する。
- CREST を ETKDG に置き換える、複数回流して和集合を取る: NCI 錯体のサンプリングの代わりにならない安い代用品か、費用が数倍になる。
- CREST の出力の番号付けを正準化する: 番号付けがパイプライン全体の添字に波及する。
- is_chiral と `_EXTERNAL_RANK_TOL` を調整する、ヒステリシスを付ける: 境界が動くだけである。
- libmsym を全しきい値 5e-2 まで緩める: 誤りが出る(ただし G5-P3 の候補としては使う)。
- basin の代表を、後から低いエネルギーのメンバーに取り替える: freq のない代表ができる。
- 負の理由の件数を回帰の基準にする: 観測量ではない。
- (分析の G5-P3 の)受け入れのしきい値 1e-6 Eh: 新しい魔法の数である。しかも acac の Cs(7.1e-6)を退けて m=2 にし、RT ln 2 ≈ 0.41 kcal/mol の誤りを持ち込む(DFT の acac のエノールは平面の Cs)。

#### スコープ判断

- 並列の NWChem と CREST の結果を、ビット単位で再現することは範囲外とする。再現性は結論の水準で定義し、design.md §7.1 に「JobStore は run の中の記憶であって、run の間の決定性を保証しない」と 1 文書く。

- A/B の比較では、上流の成果物を共有する(runcase.sh の SRC/FROM)。

### 2.6 G6 既定の理論レベルの精度

#### 化学的背景

- **非局在化誤差**
  - 近似汎関数の E(N) は分数電子数で凸に曲がり、電子や電荷が広がった構造を過安定化する(Mori-Sánchez, Cohen, Yang, PRL 100, 146401 (2008))。
  - TS では電子が広がっている(3 中心 3 電子の H 引き抜き、3 中心 4 電子の SN2、O···H···O のプロトン移動)ので、障壁が低く出る。
  - PBE0 の平均符号付き誤差は、H 移動 −4.2、重原子移動 −6.6、求核置換 −1.9 kcal/mol(Zhao & Truhlar, JPCA 109, 2012 (2005))。
  - BH9(Prasad et al., JCTC 18, 151 (2022))では、ωB97M-V、ωB97X-D、M06-2X の障壁の MAE が 2〜2.5、PBE0-XDM が 2.85 kcal/mol。M06-2X は平均で +1.05 過大である。
- **実測(プローブ、構造は hfauto の PBE0/SVPD の停留点、ΔE‡ は kcal/mol、括弧内は CCSD(T)/def2-TZVPD との差)**

  | 反応 | CCSD(T) | PBE0/SVPD | PBE0/TZVPD | ωB97X-D3/TZVPD | M06-2X/TZVPD |
  |---|---|---|---|---|---|
  | HCN→HNC | 47.81 | 46.62 (−1.19) | 46.43 (−1.38) | 46.37 (−1.44) | 46.02 (−1.79) |
  | CH3O•→CH2OH• | 33.37 | 33.01 (−0.36) | 32.71 | 33.58 (+0.21) | 32.66 (−0.71) |
  | Cl⁻+CH3Cl(錯体基準) | 13.44 | 10.45 (−2.99) | 11.15 | 15.10 (+1.66) | 13.90 (+0.46) |
  | OH+CH4(分離基準) | 6.96 | 0.79 (−6.17) | 1.87 (−5.09) | 4.03 (−2.93) | 5.82 (−1.14) |
  | 平均絶対誤差 | — | 2.68 | 2.36 | 1.56 | 1.03 |

  - 誤差の主因は汎関数で、SVPD から TZVPD にしたときの変化は ≤ 1.1 kcal/mol にとどまる。
  - M06-2X の grid は、fine と xfine で障壁の差が ≤ 0.01 kcal/mol だった。
  - S6 の ΔE_rxn は、M06-2X が −14.54、CCSD(T) が −12.77 で、**−1.8 kcal/mol ずれる**(障壁の誤差より大きい)。
  - 既存の記録では、HONO の PBE0 は +2.0 kcal/mol で、M06-2X は未測定である。
- **構造の誤差(SP//PBE0)**: S6 の PBE0 の QRC の軌跡に CCSD(T) をかけると、エネルギーの最大は PBE0 の TS より生成物側で +0.31 kcal/mol 高かった(IRCMax の意味の幾何誤差。Malick et al., JCP 108, 5704 (1998))。汎関数の誤差より 1 桁小さい。
- **NWChem の費用(TMA·(HF)2、327 基底関数、4 ranks、1 点)**
  - PBE0/TZVPD 312 s、M06-2X/TZVPD 255 s、ωB97X-D3/TZVPD 1,689 s。
  - meta-GGA と CAM/LC では解析 Hessian を使わない(`src/hessian/analytic/hess_check.F`)。
- **CCSD(T)**
  - マロンアルデヒド(227 基底関数)の (T) は、`memory total 1200 mb` では GA の確保に失敗した。`memory heap 100 stack 500 global 1300 mb` では通り、1 点約 30 分の見込みになった。
  - 開殻の ROHF-TCE は 7 原子で 1 点 5〜9 分。DLPNO は NWChem にない。
- **縮退反応の速度**
  - TS が自分の像になる場合(McIver–Stanton の反対称な遷移ベクトル。McIver & Stanton, JACS 94, 8618 (1972))、σ と m を入れた TST は片方向の流束を数える。ラベル付きで数えると、k_event = 2 × σ-TST になる。
- **トンネル**: 1 次元の Eckart の κ は、障壁と ν‡ に指数的に依存する(Eckart 1930、Johnston & Heicklen 1962)。

#### 根本原因

1. **既定の順位は PBE0/SVPD のエネルギーそのもので、非局在化誤差が 3 中心の TS を過安定化する。**(プローブで確認)discover.yaml に sp stage がなく、thermochemistry.py:98 で freq の E をそのまま使う。
2. **補正の層が既定の外にある。層に選んだ ωB97X-D3/TZVPD は、NWChem で高価なうえに、ラジカルの H 引き抜きでは不十分である。**(プローブで確認)
3. **SP//PBE0 の位置のずれは、S6 でも約 0.3 kcal/mol で副次的である。**(プローブで確認)
4. **CCSD(T) の上限は、手法の能力ではなく、全 job 共通の memory 設定(GA 50% = 600 MB/rank)から来ている。**(プローブで確認)さらに site の 1200 自体が、site の規則(ranks × 値 ≤ 0.8 × MemTotal ≈ 8.8 GB)より保守的すぎる。K2 は ranks を分け合うので、合計は同時実行でも保たれる。
5. **パネルに spin_ok がかからず、ECP 原子の芯を凍結しない。**(一部確認)method_panel は表示だけで、順位には入らない。ECP の件は相関空間の定義の不整合である。
6. **自己像の TS をもつ縮退反応で、δG_eff が RT ln 2 だけ高く出る。**(導出で確認)
   - NH3、Cl⁻···CH3Cl、H2O2 で独立に導き直した。VAL7 では 13 反応が該当する。
   - Pilgrim などの外部コードとの突き合わせは未実施。
7. **トンネル補正がない。PBE0 の ν‡(S6 で 481i)から作った κ は過小になる。**(一部確認)「過小になる」は、高レベルの ν‡ を計算していない推論である。

**反証された説明**: 「SP の対象点が、順位の読まない点まで数える」。`_state_G` は層の値の最小をとるので、状態のすべての極小が要る。VAL7 では 1 状態あたり最大 2 個で、S19 は 5 点だった(「8〜10 点」は記録と合わない)。単量体は dG_act_vs_separated に使う。この原因に基づく案(対象点を絞る G6-P2)は見送った。

**検証で加わった指摘**

- PBE0 の非局在化誤差は、障壁の値だけでなく **PES の形**も変える。PBE0 に鞍点がなければ、層の SP は障壁を直せない。S6 の平らな PES の問題(G1)ともつながる。
- 発見の段のエネルギーの選別(dft の window_kcal 6.0、rerank_sp、reaction_window_kcal、out_of_window)は、すべて PBE0 のエネルギーで行う。窓は停留点レベルの誤差より広くとる必要があり、その根拠を design.md に書くべきである。
- ベンチマークは障壁しか比べていないが、δG_eff は反応エネルギーも含む。

|---|---|---|---|
| G6-P1 | 順位を M06-2X-D3(0)/def2-TZVPD // PBE0-D3BJ/def2-SVPD にする | must | §3 X7 |

- ωB97X-D3/TZVPD を層にする: M06-2X の 6.6 倍の費用で、S6 では誤差が大きい(−2.9)。

- CBS への外挿と DLPNO の導入は、NWChem の外になるので行わない。

### 2.7 G7 コード量と責務の重なり

#### 背景

課題は化学の誤りではなく、同じ化学操作を複数の場所で書いていることと、不変条件の置き場所がずれていることにある。

- **QRC**(Goodman & Silva, Tetrahedron Lett. 44, 8233 (2003))
  - 1 次の鞍点から虚モードに沿って ±s 変位させ、両側を最適化して basin を判定する。
  - 同じ操作が 2 か所にある。minima stage の mode-follow(minimum.py:131 の `_follow`、変位は `_Point.step`:59-70)と、case の CONNECT(actions.py:349-399、変位は `_amplitude`:259-263)である。
- **高次の鞍点から降りる操作**にも規則が 2 つある。minimum.py は全ての虚モードの和の方向に押し、actions.py:266-274 の `_pushed` は 1 本だけ押す。
- **厳密な像**の判定も 2 か所にある(minima.py:87-102 と actions.py:357-367)。

#### 根本原因

1. **行数の目標を物理行数で立てたので、未達の半分以上は docstring と空行である。**(記録で確認)
   - radon raw の比較(d5fd24c → HEAD)は、LOC 10,336 → 10,609、SLOC +121、docstring +127、空行 +32、単独のコメント −7。
   - 分析では SLOC +124 と数えていたが、+121 が正しい。
   - docstring には、計画書や run の ID が約 36 件入っている。これは design.md と重なる来歴の記述である。
2. **同じ化学操作(QRC の変位、高次の鞍点からの降下、厳密な像の省略)が 2 か所に実装されている。**(コードで確認)
   - 同梱の method はすべて scf_energy_tol 1e-7 なので、qrc_drop = 1e-5 で、2 つの変位の目標は同じ値になる。VAL7/nh3_planar_seed の paths 段は hits 2 / misses 0 だった。
   - つまり鍵の一致は「既定値での一致」で、それを保証する定義がない。
3. **DFT 極小のストアが 2 つ(`Registry._basins` と `CaseRuntime.minima`)、species の原子順への写像も 2 つ(`driver._endpoint` と `hypotheses._Pool.coords`)ある。**(コードで確認)今は更新漏れは起きていない。
4. **決定表の行 9・10 は判断ではなく手順である。**(一部確認)

### 2.8 G8 多段反応の分割・緩い錯体の basin・継続

#### 化学的背景

- **S6 の PES の実像**(CH3···H2O 錯体を基準にした kcal/mol)
  - CH4···OH 錯体 +13.4〜+14.1、引き抜きの TS(−481i)+15.8、CH3OH···H の「錯体」+25.14〜+25.63(5 つの basin)。
  - O 上の置換の TS(−1418i)は +48.1、C 上の置換の TS(−1348i)は CH4···OH から +39.8。
- **CH3OH···H の 5 つの basin**
  - H 原子が CH3OH から 2.5〜5.2 Å 離れて置かれた配置で、エネルギーは 0.49 kcal/mol の幅に収まる。結合は分散の ≤ 0.5 kcal/mol しかなく、kT(0.59)と同程度である。
  - 298 K、1 atm では会合のエントロピー損失が約 6〜8 kcal/mol あるので、ΔG_assoc は正であり、化学種としては存在しない。化学的には「CH3OH + H」という 1 つの状態である。
- **平らな面では basin を分解できない**: 20 cm⁻¹ 程度の並進様のモードでは、DRIVER の許容勾配に対応する位置の不確かさが数十 bohr になる。identity の 0.05 Å / 5e-5 Eh(identity.py:21-24)は、この面で最適化が保証できる精度より桁違いに細かい。
- **熱化学の約束**: thermo は状態を (composition_id, state_label) とし、その G を最小 G とする(thermochemistry.py:16-17,136-144)。これは Curtin–Hammett の前提(Seeman, Chem. Rev. 83, 83 (1983))と、エネルギースパン(Kozuch & Shaik, Acc. Chem. Res. 44, 101 (2011))に沿う。ところが case の driver は basin の粒度で判定している。
- **原子番号付け**: 反応の端点の添字は、TS を挟んで連続していなければならない。basin は置換について不変な同値類なので、代表の添字は任意である。これは最小化学距離の原理(Jochum, Gasteiger & Ugi, Angew. Chem. Int. Ed. Engl. 19, 495 (1980))にかかわる。
- **S10 の AUTOZ**
  - QRC の側で N···H–F が 179.98° までほぼ直線になった。AUTOZ は直線の変角座標を作らない(https://nwchemgit.github.io/FAQ.html)ので、「insufficient internal variables」で停止した。
  - マニュアルでは、この状況は REDOAUTOZ(現在の幾何で座標を作り直し、Hessian を捨てる)で扱う。
- **S8(Me3N–SO2)**: N–S は気相で約 2.26 Å、結晶で約 2.05 Å の部分結合である(Oh, Kuczkowski et al., JACS 113, 4732 (1991)、Leopold et al., Acc. Chem. Res. 30, 57 (1997))。GFN2 の 2.167 Å は、しきい値 2.16 Å のすぐ外側にある。

#### 根本原因

1. **分割した子 case と仮説の端点に、QRC の側が実際に到達した添字付きの構造ではなく、basin の代表 species の添字を使っている。**(記録で確認)
   - W3 の QRC の側(jobs/25/25e558c7…/final-052.xyz)は、生成物 05c1 と添字まで同じ(C0-H1、C0-H3、C0-H4、C0-O5、H2-O5)だった。

   - その結果、見かけ上 4 本の結合が変わる架空の H スクランブルができ、torsional=False の子 → SCREEN の intermediate → split2_split1/2 → max_split_depth と連鎖した。
   - G8-3 の `hypotheses._candidates`(182)も同じ原理に反している。ただし「malonaldehyde で約 1/2 の確率で仮説が消える」は推論で、実例はない。

## 3. 横断的な根本原因と汎用設計

§2 の案のうち、同じ根本原因をもつものを 1 つの設計にまとめた。各設計には、統合した案の ID と、削除・統合できるコードを書く。

### X1 仮説の結合変化を、探索と判定の一次情報にする(根本原因 A)

統合した案: G1-P1、G1-P2、G4-P2

- **モデル Hessian を 1 つの式にする**
  - `shape_hessian(H, direction=None)` は次の 2 通りだけにする。
    - 方向があるときは P·H₊·P − κd̂d̂ᵀ(d は仮説の ρ か、反応モードの種の自分の虚モード)。
    - ないときは H₊(負の固有値を |λ| にした正定値モデル)。
  - エンジン側でモデルを推測する規則(engine.py:345-347 の first_order)は、1 行に置き換える。「−saddle_cm1 より下のモードが 2 本以上(高次の鞍点)なら as_is、それ以外は positive」。
    - これで、DME C2v の as_is と、R6 seed の positive(G4-P2)を同時に満たせる。
    - QMEngine.optimize に引数を足して呼び出し側に選ばせる案は、protocol を広げるので採らない。
  - R6 の seed を初期 Hessian から除外する条件(minima.py:142-148)を外す。
- **反応方向**: `Ctx.direction` は、ラベル付きの端点の結合変化から作る ρ にする。経路の接線と `_MIN_OVERLAP` は削除する。
- **TS のゲート**: `is_first_order_saddle` の後に `reaction_mode_character` をかける。拒否した鞍点は試行を数え、QRC はしない。
- **削除できるもの**: `_MIN_OVERLAP` と overlap テスト、接線を reaction_centre の行に制限する分岐、shape_hessian の「最も平行な固有ベクトル」の選択、engine の first_order の推測。
- **汎用性**: 結合変化のある仮説ならどれにも使え、元素・電荷・スピンに依らない。
- **リスク**: 対称な seed では、正定値モデルでも鞍点に止まりうる(安全網は mode-follow)。ρ の伸縮成分が小さい転位では、初期方向が弱い(安全網は G1-P2)。
- **真の検証**: §2.1 の G1-P1 と G1-P2、§2.4 の G4-P2 を参照。G4-P2 については、S5・S6 の R6 の seed の終点(極小か鞍点か、どの basin か)と後続のジョブ数を VAL7 と比べ、「崩れるかどうか」が変わったら不合格とする。

### X2 原子の対応の連続性と、状態の粒度(根本原因 A)

統合した案: G8-P2、G8-P1、G5-P2、G8-P7、G8-P3

1. **添字の連続性(G8-P2、must)**
   - 中間体として後段の端点になる構造(`_two_steps`、`validate_intermediate`)は、ケースの原子順の構造 x とともに保存する。
   - 具体的には、ジョブなしの SpeciesRecord(geometry = 側の opt.final)を作り、`Registry.join(basin, sid)` でメンバーにする。その species を中間体として `ctx.work.intermediate` に入れる。これで、`driver._endpoint` の `basin_coords` が連続した端点を返す。
   - DiscoveryRecord に `source_species` を足す(mode_follow なら `<parent>_mf1`、NT2 と relaxation なら trial の開始 species)。`_candidates` は ends=(source_species, product_species) にし、`_ends` は discovery 自身の端をまず使う(規則が 1 つ減る)。
2. **状態の粒度(G8-P1、must。G5-P2 を含む)**
   - 端点の (composition_id, state_label) が異なる case では、connect、`_two_steps`、`validate_intermediate` の判定キーを状態にする。同じ状態の case(宣言したねじれ、配座変換、縮退転位)では、これまでどおり basin にする。
   - 両側が同じ状態に落ちた TS は、この case にとって非反応的なので、**棄却して探索を続ける**(行 8 の振幅を広げた再試行は、同じ basin に戻った場合だけに残す)。
   - キーの集合が端点と一致すれば elementary、片側だけ一致すれば 2 段、どちらも一致しなければ reassigned とする。
   - 実際に結ばれた basin は ConnectionClaim.minima に残し、record.minima は書き換えない。
   - 端点と同じ状態で、|ΔE| < resolution、親の経路でその端との間に resolution 以上の山がない井戸は same_as_endpoint とする(G5-P2 の簡素版)。
   - design.md:162 の「中間体は他方の端点の配座でもよく」を削り、「結合変化の case の中間体は、端点と別の化学状態に限る」に書き換える。
